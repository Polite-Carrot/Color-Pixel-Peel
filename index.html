How to play

  1. Every cell is a stack of colored layers and you only see the top one.
  2. Tap a run of two or more touching cells of the same color. The whole run peels off at once, revealing the colors underneath.
  3. A single pixel on its own cannot peel. It needs a neighbour of its own color first.
  4. A cell that runs out of layers becomes a hole, and holes break up the runs around them — so the order you peel in matters.
  5. Clear every layer before the moves run out. A bigger run scores far more than several small ones, and moves you never spent are worth points too.
